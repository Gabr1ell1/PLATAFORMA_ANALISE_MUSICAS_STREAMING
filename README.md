## PLATAFORMA DE ANÁLISE DE MUSICAS STREAMING

# 🎵 Plataforma de Análise e Ordenação de Músicas

Projeto acadêmico desenvolvido em Java para a disciplina de Estruturas de Dados, com foco na manipulação de arquivos, estruturas de dados dinâmicas, algoritmos de ordenação e análise de desempenho.

## 📌 Sobre o projeto

A aplicação simula uma plataforma de análise de músicas em streaming, permitindo organizar registros musicais de acordo com diferentes critérios, como número de reproduções, avaliação média, ano de lançamento e duração.

O projeto busca aplicar, na prática, conceitos de programação e estruturas de dados, além de comparar o comportamento de diferentes algoritmos de ordenação por meio de testes de desempenho.

## 🎯 Objetivos

- Aplicar conceitos de estruturas de dados dinâmicas.
- Manipular registros armazenados em arquivos de texto.
- Implementar operações de inserção, consulta, atualização e exclusão de registros.
- Ordenar os dados utilizando diferentes algoritmos.
- Comparar o desempenho dos algoritmos implementados.
- Explorar tabelas hash para organizar e consultar informações relacionadas a países e cidades.

## ⚙️ Funcionalidades

- **Manipulação de dados:** operações de cadastro, leitura, atualização e exclusão de registros musicais.
- **Persistência em arquivos:** armazenamento e recuperação dos registros por meio de arquivos de texto.
- **Ordenação:** implementação dos algoritmos Bubble Sort, Insertion Sort, Selection Sort e Merge Sort.
- **Critérios de ordenação:** organização dos registros conforme atributos definidos na aplicação.
- **Pesquisa de registros:** consulta de informações nos arquivos de entrada e de saída.
- **Estruturas de dados:** aplicação de estruturas dinâmicas e tabelas hash conforme os requisitos do projeto.
- **Análise de desempenho:** coleta de métricas para comparar a execução dos algoritmos.

*Observação: mantenha na lista somente as funcionalidades concluídas e testadas na versão disponibilizada.*

## 🧮 Algoritmos de ordenação

| Algoritmo | Estratégia principal |
|---|---|
| Bubble Sort | Compara elementos adjacentes e realiza trocas quando necessário. |
| Insertion Sort | Insere cada elemento na posição adequada dentro da parte já ordenada. |
| Selection Sort | Seleciona o elemento apropriado para a próxima posição. |
| Merge Sort | Divide o conjunto em partes menores, ordena-as e intercala os resultados. |

Os algoritmos são utilizados para estudar diferentes estratégias de ordenação e analisar fatores como complexidade, quantidade de comparações, movimentações e tempo de execução.

## 📁 Organização dos dados

A aplicação utiliza arquivos de texto para armazenar os registros e os resultados das operações.

- `entrada.txt`: arquivo utilizado para armazenar os dados de entrada.
- Arquivos de saída: armazenam os resultados produzidos pelos algoritmos de ordenação, conforme a nomenclatura definida na implementação.
- Arquivos de log e relatórios: utilizados para registrar operações e métricas de desempenho, conforme implementado.


3. Verifique a configuração do JDK exigido pelo projeto.

4. Certifique-se de que os arquivos de entrada necessários estejam disponíveis no caminho esperado pela aplicação.

## 📊 Análise de desempenho

O projeto prevê a comparação dos algoritmos de ordenação a partir de métricas coletadas durante sua execução. A análise permite relacionar os resultados experimentais à complexidade teórica de cada algoritmo e observar como o comportamento varia conforme o volume de dados.

Os resultados e as conclusões devem ser consultados no relatório acadêmico produzido pelo grupo.
